Nova Base de Dados

Esta base funciona no plano Spark: o CSV/Excel é lido diretamente no navegador e os dados importados ficam sincronizados no Firestore. O arquivo físico não é enviado ao Firebase Storage.

Excluir dados de demandas

A exclusão é permanente no Firestore. Você pode remover todo o histórico de demandas ou somente um ano/mês. Servidores e auditoria não serão apagados.

Limpar histórico de auditoria

A limpeza remove permanentemente os registros da coleção de auditoria no Firestore. Esta ação não apaga demandas, servidores, bases ou configurações.
